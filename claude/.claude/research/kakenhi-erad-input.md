# 科研費 e-Rad（科研費電子申請システム）の入力仕様

研究計画調書のうち **Web入力項目**（様式の添付ファイルではない側）を入力するときの実務メモ。
2026-09-01 に令和9年度・若手研究の実物で確認した内容が基。**種目共通の仕様が多い**
（経費明細の様式は基盤B・学変B・若手でバイト完全一致を確認済み）。

一般的なワークフローは `phase-proposal.md`。ここは e-Rad 側の落とし穴だけを扱う。

> **記入要領に書かれていない仕様が多い。** 公募要領・Web入力要領はどちらも「追加」ボタンでの
> 手入力しか説明していない。以下は実物と過去の提出ファイルから起こしたもので、
> **推測で「たぶんこうだろう」と決めた形式は通らない**（下の CSV の項がまさにその失敗）。

## 経費明細の CSV 読み込み

経費明細画面には**空テンプレート CSV のダウンロードと読込**がある（記入要領には載っていない）。
行数が多いときは手入力より速い。

**空テンプレートに形を合わせても通らない。** ヘッダのバイト列をテンプレートに一致させる方針で
作ったファイルは読込に失敗した。**過去に実際に提出できたファイルの形式に合わせること。**
`~/Documents/grant/*/budget_submit.csv` に実績がある（2024年・2025年の基盤B）。

| 項目 | 実績のある形式 |
|---|---|
| 文字コード | CP932・BOM なし |
| 改行コード | **LF**（CRLF ではない） |
| ヘッダ行 | **全列をダブルクォートで囲む** |
| 文字列の列 | **ダブルクォートで囲む**（数値の列は囲まない） |
| 使わない列 | **文字列列は `"0"`、数値列は `0`** で埋める。**空文字にしない** |
| 設備備品費(A) 行の事項欄 | **`NA`（クォート無し）** |
| 並び順 | 費目区分（A→F）→ 年度 |

列は8つ:
`費目区分 / 年度 / 品名・仕様 / 設置機関 / 事項 / 数量 / 単価 / 金額`

行の形は2種類だけ。

```
"A",2027,"ワークステーション（メモリ64GB・SSD1TB）","○○大学",NA,1,750,750
"B",2027,"0","0","4Kモニタ27インチ 1台×80千円",0,0,80
```

- **費目区分は A=設備備品費・B=消耗品費・C=国内旅費・D=外国旅費・E=人件費/謝金・F=その他**
- **事項欄にカンマを入れない**（CSV が壊れる）。単価は「1200円」と書く
- **事項欄は短くする。** 実績のある最長は 32 バイト。上限は要領に書かれていない。
  積算の詳細は事項欄ではなく後述の「必要性・積算根拠」欄に書く
- 金額は**千円単位・千円未満切り捨て**。読込後に必ず**再計算ボタン**を押す

## 必要性・積算根拠の欄（条件付きではなく必須）

記入要領は無条件で求めている。**90% ルールは、この上に重なる追加要件**であって、
「90% を超えたときだけ書く欄」ではない。

- 「入力した**設備備品費及び消耗品費**の必要性・**積算根拠**について入力すること」
- 「入力した**旅費、人件費・謝金及びその他**の必要性・**積算根拠**について入力すること」

**欄は2つ。どちらも埋める。各500字以内で、改行も全角1文字として数える。**
旅費・人件費謝金・その他を1欄に収めるので、後者は密度が高くなる。

追加要件（該当したらさらに書く）:
- **設備備品費**が当該年度の研究経費の 90% 超
- **消耗品費・旅費・人件費/謝金**のいずれかが 90% 超
- **「その他」で特に大きな割合を占める経費がある場合**——**その他には 90% の下限が無い**。
  判断ベースなので、3〜4割でも該当しうる

## 文字の禁則（PDF 生成器が化ける）

e-Rad の PDF 生成器（IOWebDOC）は、**JIS X 0208 内の文字でも変換に失敗して
数値文字参照のまま印字する**ことがある。2026-09-01 に実物で確認:

> 年600**`&#12316;`**650時間  ← 「〜」(U+301C WAVE DASH) が化けた

**Web入力欄にはダッシュ・波線を一切入れない。** 「〜」も「―」(U+2015) も避け、
「AからB」「、すなわち」等に書き換える。EM DASH (U+2014) は論外。
**本文（様式の添付ファイル）は LaTeX/Word で別に組むので、この制約は掛からない。**

## 各欄の上限（令和9年度・若手研究で実測）

| 欄 | 上限 | 備考 |
|---|---|---|
| 研究課題名 | **80 バイト**（全角40字） | 全角英数字も2バイト。**英字略語は半角で入れる**——全角変換されると超過しやすい |
| 必要性・積算根拠（各欄） | **500 字**・改行も1字 | 上記のとおり2欄 |
| 研究費の応募・受入等の状況「相違点及び応募理由」 | **1課題あたり 600 バイト** | 表の行ごとにある。**本応募研究課題の行も埋める** |
| 学術的「問い」 | 500 字・任意 | **PDF に出力されない**ので提出前 PDF では検証できない。KAKEN 公開用で審査には使わない |

「研究費の応募・受入等の状況」も **PDF に出力されない**が審査委員は画面で見る。
**e-Rad の応募・受入情報の連携に 30〜60 分（混雑時は数時間）かかるので、締切当日に入力しない。**

## 提出前 PDF の機械検証

生成された PDF を目視だけで確認しない。テキストを抜いて突き合わせる。

```sh
pdftotext -layout 提出前.pdf /tmp/s.txt
grep -n "&#" /tmp/s.txt                 # 文字化け（実体参照）の検出。0件が正
grep -n $'〜\|～\|―\|—' /tmp/s.txt      # 危険文字の残存
pdfinfo 提出前.pdf | grep Pages          # 頁数（明細は各2頁が上限）
```

- **1頁目の研究経費の総括表は e-Rad が明細から自動計算している。** ここが期待値と一致すれば、
  明細行は正しく取り込まれている（行単位の照合より確実で速い）
- 明細の事項欄は狭いセルで折り返され、**他列の文字と同じ行に混ざる**。
  テキスト検索で「見つからない」と出ても、たいていは折り返しであって欠落ではない
- 修正版が出たら**前版と `diff` を取る**。意図した箇所だけが変わったことを確認する

## 執行段階の自由度（申請時の内訳に縛られすぎない）

- **若手研究・基盤(B)(C)等は基金種目**（公募要領の「助成金種別」で確認する）。基金では
  **次年度使用に事前の繰越手続きが要らない**（実施状況報告書に金額と理由を書くだけ）。
  逆方向も**前倒し支払請求**でできる。年度配分は計画であって拘束ではない
- **費目間流用は「直接経費総額の 50%（その額が 300 万円以下の場合は 300 万円）」を
  超えるときだけ承認が必要**（様式 C-4-1）。総額 1,000 万円以下の課題では
  **下限側の 300 万円が効く**ので、現実の組み替えはまず全部この範囲内
- **流用の「費目」は府省共通の4区分**（物品費・旅費・人件費/謝金・その他）で、
  e-Rad 入力の6区分ではない。設備備品費と消耗品費は同じ物品費、国内旅費と外国旅費は同じ旅費。
  同一区分内の品目の入れ替えは流用ですらない
- ただし**金額の融通と研究計画の変更は別レイヤー**。本文に無い活動を始めるなら手続きの要否を確認する

**帰結: 本文に裏打ちの無いものを経費に載せない。** 必要になったら執行段階で同じ費目の中で
対応できる。載せると「経費欄の必要性が本文に無い」という不整合になり、そちらのほうが高くつく。

## 学内手続き（静岡県立農林環境専門職大学）

競争的資金に応募するたび、研究計画調書とは別に**別紙様式1「個人向け競争的研究資金応募届出書」**を
学長宛に出す（「個人向け競争的研究資金の取扱指針」第2条）。過去の提出物は `~/Documents/grant/*/`。

- 本文の文言は版によらず同一。変わるのは記入値だけ
- **間接経費＝直接経費の 30%** を書く（調書に書くのは直接経費だけなので混同しない）。
  直接経費に端数があると、年度ごとに算出して積み上げた額と、合計に30%を掛けた額が
  1千円ずれる。**年度ごとに切り捨てて積み上げる側**を採る
- **調書の金額を変えたら、この届も必ず直す。** 別ファイルなので取り残しやすい
